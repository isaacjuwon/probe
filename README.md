Dev-only in-app REST client for Laravel.

## Installation

You can install the package via Composer:

```bash
composer require isaacjuwon/probe --dev
```

You may publish the configuration:

```bash
php artisan vendor:publish --tag="probe-config"
```

Or publish the public assets:

```bash
php artisan vendor:publish --tag="probe-assets"
```
